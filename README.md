# 键盘锁 KeyboardLock

临时锁住笔记本自带键盘，**鼠标和滚轮完全不受影响**。

适合这些场景：在键盘上垫书/纸张写字、清理键盘、防猫踩键盘、给小孩看视频时防止乱按。

|---|---|
| ![](assets/screenshot.png) | ![](assets/screenshot-locked.png) |

## 特点

- **只锁键盘，不碰鼠标**：只安装 `WH_KEYBOARD_LL` 键盘钩子，全程没有任何鼠标钩子
- **Ctrl + Alt + U 一键锁 / 解**，也可以直接用鼠标点界面里的按钮
- 快捷键按**虚拟键码**匹配，不受输入法、键盘布局影响；AltGr 布局不会误触发
- 锁定期间窗口自动置顶，随时能点到解锁按钮；关掉进程或从托盘退出，键盘**立刻**恢复
- **关窗口收进托盘**：`–` 最小化到任务栏，`×` 只是隐藏窗口，锁定状态保持不变
- **可选开机静默启动**：在「启动」文件夹放一个带 `--silent` 参数的快捷方式，开机自动驻留托盘、不弹窗口
- 便携单文件：免安装、免管理员权限、不写注册表、不联网、不依赖 WebView2 运行时

## 使用

1. 双击 `KeyboardLock.exe`
2. 点「锁定键盘」，或按 `Ctrl + Alt + U`
3. 解锁：再按一次 `Ctrl + Alt + U`，或用鼠标点「解锁键盘」按钮

锁定期间所有按键（包括 Win、Alt+Tab、媒体键）都不会传给系统，但鼠标移动、点击、滚轮一切正常。

### 窗口与托盘

- 点右上角的 `–`：最小化到任务栏
- 点右上角的 `×`，或未锁定时按 `Alt+F4`：窗口收进通知区域（"显示隐藏的图标"里），**锁定状态保持不变**
- 左键单击托盘图标，或再次双击桌面快捷方式：重新显示窗口
- 右键托盘图标：显示主界面 / 锁定·解锁 / 开机静默启动 / **完全退出**（只有这里才会真正结束进程）

## 工作原理

程序用 `SetWindowsHookEx(WH_KEYBOARD_LL)` 装一个全局低层键盘钩子，只订阅键盘，不碰鼠标。

钩子运行在一条专用后台线程上（自带空消息循环，优先级 Highest）。低层钩子回调必须在约 1 秒内返回，超时数次后 Windows 会静默摘掉钩子；若放在 UI 线程上，一次窗口重绘或弹窗就可能拖慢全系统每一次按键。

每次按键先交给一个纯托管的状态机（`src/KeyFilter.cs`，不调用任何 Win32 API，可脱离钩子单独测试）决定：放行、吞掉，或者切换锁定。

### 成对原则

系统看到的每个键，按下与抬起必须成对，否则要么卡键、要么漏键。状态按虚拟键码记在 256 位图里，热路径零分配、无锁：

| 按下时 | 自动重复 | 抬起时 | 解决什么 |
|---|---|---|---|
| 放行 | 放行 | 放行 | 锁定瞬间已交给系统的 Ctrl / Alt，松开时必须送达，否则滚轮变成 Ctrl+滚轮、点击变成 Ctrl+点击 |
| 吞掉 | 吞掉 | 吞掉 | 解锁时按住 Ctrl+Alt+U 不放，不会漏出 "uuu"；也不会漏出孤立的 Alt 抬起去激活前台程序的菜单栏 |
| 没见过（钩子装上前就按着） | — | 未锁定放行 / 锁定吞掉 | 用 Win+R 回车启动程序时，Enter 的按下发生在钩子安装之前；吞掉它的抬起会让系统一直认为 Enter 按着 |

### 快捷键

U 键按下时 Ctrl、Alt 同时按着（左右均可，Shift 不影响）即切换锁定。组合键的整组按键按上表第二行处理，按住不放只会切换一次。

某些键盘布局（AltGr）下，系统会在右 Alt 前伪造一个左 Ctrl，其扫描码带 `0x200` 标记。它被单独记录，不算作"按住了 Ctrl"，因此 AltGr + U 不会误触发。

### 静默超时

连续 5 秒没有任何按键事件，就清空"按住"记录。UAC 提示、Ctrl+Alt+Del 安全桌面、管理员窗口里的按键，普通权限的钩子收不到，按住状态可能已经过期；不清掉的话，之后单按一下 U 就可能误触发快捷键。

### 钩子生命周期

- 锁屏 / 切换用户 / 远程连接回来后，清掉期间残留的按住状态
- 睡眠唤醒后重装一次钩子，防止系统在休眠期间把它摘掉
- 启动失败（被杀软拦截等）时界面明确提示，并禁用锁定按钮

## 已知限制

- 仅 Windows 10 / 11
- 锁的是**整个系统**的键盘，不是某一个窗口
- 有窗口以管理员权限运行并处于前台时（UAC 提示、管理员程序），普通权限的钩子收不到按键，此时锁定无效——这是 Windows 的安全机制，不是 bug；`Ctrl + Alt + Del` 任何时候都能用
- 程序不区分真实按键与软件注入的按键：锁定期间 AutoHotkey、屏幕键盘、远程桌面注入的按键同样会被吞掉
- exe 未做代码签名，从网络下载后首次运行可能触发 SmartScreen 提示，点「更多信息 → 仍要运行」
- 部分杀毒软件对"键盘钩子"敏感，可能误报。源码就在本仓库，可自行核对、自行编译

## 项目结构

```
src/
  KeyboardLock.cs     窗体、托盘、单实例唤醒、SystemEvents 接线
  KeyboardHook.cs     钩子线程与生命周期
  KeyFilter.cs        按键决策状态机（纯托管，不依赖 Win32）
  AutoStart.cs        「启动」文件夹快捷方式
  AluPanelView.cs     自绘面板控件（鼠标命中、局部重绘）
  AluPanelRenderer.cs 绘制编排
  alu/                分层绘制模块（机身 / 标题栏 / 滑块槽 / 状态灯 / 主键 / 页脚）
tests/
  KeyFilterTests.cs   状态机单元测试
```

## 自行编译

需要 Windows + .NET Framework 4.x（`csc.exe` 随系统提供）：

```powershell
.\build.ps1
```

产物在 `dist\KeyboardLock.exe`。也可以用 .NET SDK 构建（需要 `dotnet` 命令，会从 NuGet 取 net48 参考程序集）：

```powershell
dotnet build
```

两种方式编译的是同一套源码。状态机单元测试不安装任何钩子、不碰真实键盘：

```powershell
.\tests\run-tests.ps1
```
